# Astra Survival

An original browser arena roguelike set beneath a shattered sky. Choose a Kept, brave twenty Pulses across three Vitrines, and trade gathered Glint for a build that can survive the final Warden.

## Development

The game uses browser-native ES modules, Canvas and Web Audio. Run a static HTTP server at the repository root, then open its URL. No runtime downloads or paid assets are required.
