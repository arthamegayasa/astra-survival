# Original assets

All shipped artwork, interface elements, names, melodies and sound effects were created for Astra Survival by the project team. No external art, samples, fonts or music files are distributed.

| Source | Contribution |
| --- | --- |
| render.js | Procedural observatory panorama, three arena environments, original sprite designs, lighting, particles and attack effects |
| audio.js | Six original synthesized arrangements, adaptive percussion, glass instruments and gameplay sounds |
| icon.svg, style.css, index.html | Astra emblem and interface |
| game.js, build.js, app.js | Enemy identities, classes, equipment, encounter names and game text |
