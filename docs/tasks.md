# Release milestones

| Stage | Delivered |
| --- | --- |
| Foundation | Public repository, design scope, original asset policy |
| Combat and builds | Twenty Pulses, three classes, three biomes, Wardens, three boss encounters, eight weapons, thirty Keepsakes, six tag synergies |
| Presentation | Pixel-art dioramas, original sprite art, six synthesized musical arrangements, distinct danger and reward cues |
| Player experience | Title, selection, shop, Archives, remappable bindings, touch controls, independent audio levels, reduced effects and resumable expeditions |
| Release verification | Fourteen passing Node regressions including a seeded full victory. Keyboard, Rite, pause, rebinding and reload tested in Chromium, Edge, Firefox and Windows WebKit. Public Pages tested through a real-time first Pulse, shop reload and second Pulse. |

The renderer uses Canvas to keep the download small. The simulation runs at a fixed 60 Hz. Storage belongs to the current browser profile. Audio requires an initial player gesture. Audio synthesis was verified in Chromium and Firefox. Desktop Safari and physical mobile devices were not tested.
